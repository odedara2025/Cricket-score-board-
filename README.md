# 🏏 Live Cricket Scoreboard

A dynamic, web-based cricket scoreboard built with **HTML**, **CSS**, and **JavaScript**. Perfect for tracking runs, wickets, overs, and player statistics in real-time during friendly matches or practice sessions.

## ✨ Features

- **Real-time Score Update** – Add runs (1,2,3,4,6) and update wickets instantly.
- **Bowler & Batsman Stats** – Track runs, balls faced, and overs bowled.
- **Over Counter** – Automatically calculates overs from total balls bowled.
- **Run Rate & Required Run Rate** – Useful for chase targets.
- **Extras Support** – Add wides, no-balls, leg-byes, and byes.
- **Reset Match** – Clear all scores and start fresh.
- **Responsive Design** – Works on desktops, tablets, and mobile screens.

## 🛠️ Tech Stack

- **HTML5** – Structure of the scoreboard.
- **CSS3** – Styling, layout, and responsive design.
- **JavaScript (ES6)** – Dynamic updates, logic for runs/overs/wickets.
